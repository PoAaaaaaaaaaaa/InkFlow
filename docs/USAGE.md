# 使用指南

## 第一次打开

1. 点右下角 **新建作品**，填作品名、题材、一句话故事、核心设定。
   - 「一句话故事」和「核心设定」会直接喂给规划 Agent，写得越具体，大纲越准；
   - 创建后会自动生成第 1 章，不会出现空白写作台。
2. 进入写作台，点右下角 **AI 写作** 展开 Agent 面板。

## 面板上的 8 个动作

| 动作 | 什么时候用 | 会发生什么 |
|---|---|---|
| **生成整章** | 本章还没写 | 先自动生成细纲（若你还没写），再写正文 |
| **智能续写** | 写到一半卡住 | 读取前文末尾 + 检索设定，只产出新增部分（不会重复已有文字） |
| **润色** | 初稿写完 | 改病句、删冗余、调节奏，**不改情节** |
| **校对** | 定稿前 | 找错别字、语法、标点问题 |
| **主编审阅** | 想听真话 | 开篇吸引力/推进效率/情绪张力/钩子强度 + AI 腔风险 |
| **设定一致性** | 长章节写完 | 比对角色卡与设定集，找矛盾 |
| **质检** | 随时 | 本地规则引擎，秒出分（不消耗 token） |
| **交接笔记** | 本章写完 | 压成 400 字供下一章注入，长篇不崩的关键 |
| **文风蒸馏** | 写了一段时间后 | 从已有章节提炼你的写作指纹 |

> **AI 产出不会自动进正文。** 生成结果先显示在预览卡里，
> 点「插入正文」才合并，点「丢弃」就扔掉。你的手稿永远由你掌控。

## 让 AI 更像你：文风 DNA

写到 3~5 章之后，点 **文风蒸馏**。系统会从你最长的几章里提取：

- 平均句长、短句/长句占比、句长起伏（节奏感）
- 段落长度、对话行占比
- 每千字比喻密度、情绪句占比
- 你的高频用语，以及**需要克制的过度使用词**

之后每次生成都会带上这份约束。质检时还会算「文风吻合度」，
低于 70 分会提醒你这段走味了。

## 伏笔台账

写作台上方的抽屉里可以查看伏笔。每条伏笔记录：

- 第几章**埋设**
- 第几章**推进**（最近一次）
- 计划第几章**回收**

系统会自动预警：

- **逾期**：超过计划章节 +3 章仍未回收（高重要度伏笔会升级为严重问题）
- **停滞**：15 章没有推进
- **过载**：开放伏笔超过 25 条

> 逾期伏笔会让章节无法「定稿」——这是质量门禁的一部分。

## 质量门禁与章节状态

章节状态：`草稿 → 已润色 → 定稿`

- 点标题栏的状态标签可以切换；
- **升到「定稿」时必须通过门禁**：综合评分 ≥ 阈值（默认 70）且无严重问题；
- 阈值可以在设置里调。

评分由四个维度加权（缺失维度不参与，避免无端扣分）：

| 维度 | 权重 | 看什么 |
|---|---|---|
| 连贯性 | 30% | 角色称呼、场景过渡、代词指代、数值一致 |
| 流畅度 | 30% | 长句、用词重复、标点、词汇广度、段落长度 |
| 文风吻合 | 20% | 与你的文风 DNA 的接近程度 |
| 叙事连续性 | 20% | 与上一章的衔接、悬念是否断线 |

## 选择 AI 引擎

设置页 → **端侧 AI 引擎**，可以看到四个引擎的实时可用性。

| 引擎 | 什么时候能用 | 特点 |
|---|---|---|
| Gemini Nano | 设备支持 AICore 且模型已下载 | 完全离线，四类开箱能力 |
| LiteRT-LM | 自行导入 `.litertlm` 模型 | 支持 GPU/NPU，长文创作主力 |
| 云端模型 | 你填写了 API Key 并开启 | 质量最高，但文本会离开设备 |
| 离线写作助手 | 永远可用 | 生成写作骨架，不假装是 AI 正文 |

### 导入 LiteRT-LM 模型

把 `.litertlm` 模型文件放到应用私有目录：

```
/data/data/com.inkflow.app/files/models/
```

（需要 root 或通过应用的「导入模型」功能。模型文件通常 1~4GB。）

### 配置云端模型

设置页填三项：

- **接口地址**：`https://api.openai.com/v1`（会自动补 `/chat/completions`）
- **API Key**：只存本机
- **模型名**：`gpt-4o-mini` / `deepseek-chat` / `qwen-max` 等

填完点 **测试连接** 确认可用。

> 也支持本地 Ollama：地址填 `http://127.0.0.1:11434/v1`。

### 引擎优先级

默认顺序 `Nano → 本地模型 → 云端 → 离线助手`，靠前的失败会自动降级。

如果你想「长篇生成优先用云端保质量」，打开那个开关即可。

## 长篇写作建议流程

```
1. 新建作品，认真写「一句话故事」和「核心设定」
2. 设置里点「构建作品蓝图」→ 自动生成角色卡与初始伏笔
3. 点「规划全书」→ 生成分卷分章大纲
4. 逐章写作：
   ├─ 生成整章 → 预览 → 插入正文
   ├─ 手动修改打磨（这才是作者的工作）
   ├─ 质检 → 看问题列表 → 修
   ├─ 一致性检查
   ├─ 交接笔记（每章必做，长篇不崩的关键）
   └─ 定稿（过门禁）
5. 每 5~10 章点一次「文风蒸馏」，让 AI 持续贴近你的笔感
```

## 章节历史版本

每次保存前，旧正文会自动存为历史版本（保留最近 40 版）。
误删或改坏了可以回滚。

## 数据在哪

全部在本地 Room 数据库：`/data/data/com.inkflow.app/databases/inkflow.db`

- 不联网、不同步（除非你开启云端引擎）；
- 卸载应用会删除数据，重要稿件请自行导出备份。
